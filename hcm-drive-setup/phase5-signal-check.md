# Phase 5 — Daily Routine: The Signal Check

Heritage Craft Media · 10 minutes every morning keeps the railway running.

---

## The 10-Minute Signal Check

Run this every morning before starting work. Nothing piles up if this is done daily.

| Step | Action | Time |
|------|--------|------|
| 1 | Open **00 THE SIDING** — move any files to their terminal using the SRV / CRS / APP code | 3 min |
| 2 | Rename any file that does not have a business code prefix. If you can't name it, leave it in the Siding | 2 min |
| 3 | Check **Discord** for any Make.com automation alerts from overnight | 1 min |
| 4 | If you finished something yesterday — move the FINAL version to its terminal and drag drafts into the Repair Shed | 2 min |
| 5 | One shortcut check — if you used a file in two places this week, add the shortcut now before you forget | 2 min |

**Total: 10 minutes.** Stop there. Do not get drawn into filing everything — just the Siding and yesterday's work.

---

## The Fog Day Protocol

On days when the brain fog is heavy, follow only these two rules:

### Fog Day Rule 1 — The Siding is your friend
Do not try to file things properly. Drag everything into **00 THE SIDING**. It will wait for you. Nothing is lost.

### Fog Day Rule 2 — Name before you close
Before you shut down for the day, rename at least **one file** in The Siding using its business code.
Just one. That is enough.

## File Naming Formula

```
[CODE] - [Description] - [Tool/Version]
```

| Code | Terminal | Example |
|------|----------|---------|
| SRV | Services | `SRV - Project Proposal - HubSpot v2` |
| CRS | Courses | `CRS - Script Module 1 - HeyGen` |
| APP | Apps | `APP - LoginFlow Spec - Notion` |
| FIN | Finance | `FIN - March Expenses - Xero` |

**Heavy Rail (video files):**
```
CRS-[ID]-[Module]-[Lesson]-[Status]

CRS-001-M02-L04-RAW        ← raw footage
CRS-001-M02-L04-HEYGEN     ← AI clip from HeyGen
CRS-001-M02-L04-FINAL      ← finished — goes to Bunny, never edit again
```

---

## The 3-Click Rule

> If you click more than **3 folders deep** to find a file, it is buried too deep.

Fix it: pull the file up a level, or add a Shortcut from a higher folder.

---

## The Shortcut Signal

A shortcut in Google Drive has a **small arrow icon** on the bottom-left of the folder thumbnail.
- Arrow present = master file lives elsewhere — you are looking at a link
- Removing the shortcut does NOT delete the original file

---

## Weekly Monday Trigger (Make.com Scenario 1)

Make.com will automatically send a Discord message every Monday at 8:00 AM if there are files in The Siding. When you see that message, that is your Signal Check prompt.

---

## Quick Reset — If the system has been neglected

If the railway has been ignored for a few weeks:

1. Do not panic. Drag everything loose into **00 THE SIDING** first.
2. Then do one Signal Check per day (10 minutes only) until cleared.
3. Do not try to fix everything in one session — that is how fog days get made worse.
