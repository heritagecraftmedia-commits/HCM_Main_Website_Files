## File Naming Formula

```
[CODE] - [Description] - [Tool/Version]

SRV - Smith - Contract - v1
CRS - Script Module 1 - HeyGen
APP - HCMApp - BUG - 2025-04-07
FIN - March Expenses - Xero
```

**Video files (Heavy Rail):**
```
CRS-[ID]-[Module]-[Lesson]-[Status]
CRS-001-M02-L04-FINAL
```

## HeyGen → Bunny in 7 Steps

```
1. Generate in HeyGen
2. Download → B.02 [Course] > 02 HEYGEN ASSETS
3. Edit using RAW + HEYGEN files
4. Export FINAL → B.03 EXPORTS (name: CRS-ID-Mx-Lx-FINAL)
5. Upload B.03 FINAL → Bunny
6. Delete from computer Downloads
7. Social reuse? → Add Shortcut. Never duplicate.
```

## 3 Rules That Prevent Chaos

1. **3-Click Rule** — More than 3 folders deep = buried too deep. Add a Shortcut.
2. **One-Way Traffic** — Video files only move RAW → HEYGEN → PROJECT → EXPORT → Bunny. Never backwards.
3. **Shortcut not Duplicate** — If a file belongs in two places, the master stays in one terminal. The other location gets a Shortcut (arrow icon).
